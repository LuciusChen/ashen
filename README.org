* Introduction
Ashen is a personal, low-saturation color theme for Emacs, evolved from a
fork of the Rosé Pine port.  It provides two variants:

- =ashen-night=: dark theme with a charcoal base, dusty rose, gold,
  periwinkle and lilac accents.
- =ashen-day=: light theme with a warm white base, teal-gray text and
  dusty rose accents.

The palette is defined in terms of semantic color keys and can be
overridden at runtime, so you can adjust the theme to your taste without
editing the source.

* Installation
Ashen targets Emacs 24.1 or newer.

** straight.el (recommended)
#+BEGIN_SRC emacs-lisp
(use-package ashen
  :straight (ashen :host github :repo "LuciusChen/ashen")
  :config
  (load-theme 'ashen-night t))
#+END_SRC

Or without =use-package=:

#+BEGIN_SRC emacs-lisp
(straight-use-package
 '(ashen :host github :repo "LuciusChen/ashen"))
(load-theme 'ashen-night t)
#+END_SRC

** Manual installation
Clone the repository and add it to your load path:

#+BEGIN_SRC shell
git clone https://github.com/LuciusChen/ashen.git ~/.emacs.d/ashen
#+END_SRC

#+BEGIN_SRC emacs-lisp
(add-to-list 'load-path "~/.emacs.d/ashen")
(add-to-list 'custom-theme-load-path "~/.emacs.d/ashen")
#+END_SRC
* Usage
Activate a theme with:

M-x load-theme RET ashen-night RET

M-x load-theme RET ashen-day RET

Or programmatically:

#+BEGIN_SRC emacs-lisp
(load-theme 'ashen-night t)
#+END_SRC
* Customization
Each variant has its own palette.  The main semantic keys are:

- =background=, =alt-background=, =current-line=, =selection=
- =foreground=, =comment=
- =rose=, =gold=, =love=, =amber=, =leaf=, =foam=, =pine=, =iris=

as well as the diff colors =bg-added=, =bg-changed=, =bg-removed= and
their =*-faint= / =*-refine= / =fg-*= companions.

Override the palette with the following options:

- =ashen-common-palette-overrides=: applied to both variants.
- =ashen-night-palette-overrides=: applied to =ashen-night= only.
- =ashen-day-palette-overrides=: applied to =ashen-day= only.

Each override is an alist of (KEY . VALUE).  VALUE is either a color
string like ="#000000"= or another palette key (a symbol) whose color
should be reused.  Per-variant overrides take precedence over common
ones.

#+BEGIN_SRC emacs-lisp
;; Make the night background pure black.
(setopt ashen-night-palette-overrides '((background . "#000000")))

;; Use the foreground color for comments in both variants.
(setopt ashen-common-palette-overrides '((comment . foreground)))

;; Swap the night rose accent with the love accent.
(setopt ashen-night-palette-overrides '((rose . love)))
#+END_SRC

After changing an override, reload the theme for it to take effect:

M-x load-theme RET ashen-night RET

Inspect the effective palette at any time with:

M-x ashen-palette RET night

M-x ashen-palette RET day
